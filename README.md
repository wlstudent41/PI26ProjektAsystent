# PI26ProjektAsystent
win your exams w/ this super cool exam winning tool with no virus

## Uruchomienie
Upewnij się, że w terminalu jest wybrane directory PIprojS26zad6, czyli folder bazowy projektu.

W środowisku pythona uruchom plik manage.py z komendą runserver. 
> python ./manage.py runserver

## Testy
Aby uruchomić testy jednostkowe projektu, uruchom plik manage.py z komendą test.
> python ./manage.py test
